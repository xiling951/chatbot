# 可信身份与绑定现况

当前代码支持微信本人白名单，以及QQ官方Bot的一次性本人登记；尚未实现M07双端绑定或跨平台共享。微信与QQ默认保留独立person/scope，昵称相同、正文自称本人、平台能发送消息均不构成身份合并或授权。

可信键为平台实例、实际机器人账号和服务端事件sender；scope还包括角色与私聊/群可见范围。固定AstrBot v4.29.3的微信self_id是适配器ID，QQ C2C self_id是unknown_selfid，均不能当实际账号。插件改读受控bot_account_ids，分别来自本人确认的微信扫码账号、QQ官方扫码AppID；缺失即停止处理，切换账号不会读另一个机器人的记忆。

微信仅扫码确认的owner进入白名单，其他用户及群消息静默拦截。QQ首次扫码仅保存禁用候选；本次用户另行明确授权“本人与新测试机器人的QQ单聊”，再由activate_qq.py在服务停止时配置该适配器及空白名单。脚本拒绝替换已有owner或在运行中覆写配置。

QQ登记在Codex聊天提供16位随机十六进制一次性码，有效10分钟，本机只存哈希。用户在目标QQ单聊发送 /验证本人 码；插件核对已获测试授权、实例、当前SDK实际AppID、受控AppID、有效期、非群和非空sender。只有哈希匹配才把该可信事件sender登记为唯一owner，先消耗码再写白名单，中断后保持关闭；无效消息不回复、不调用模型，也不创建事实。已有owner不被另一个码覆盖。这个过程只核实QQ本人，不共享微信记忆或允许好友/群。

本地检查覆盖错误实例/AppID、错误码、过期、群、停止、未授权、重复码、已有owner不覆盖和真实框架类的无模型登记。两账号隔离有本地证据；手机登记与收发结果见reports/P6.md，不能用离线测试替代。

M07仍需实现：双端验证后单次短期绑定码、明确共享范围、私群边界、撤销与解绑、受影响上下文清理、变更审计以及旧快照不能复活授权。当前没有绑定/共享命令，不将一次QQ本人登记冒充跨平台绑定已完成。不会仅凭昵称或模型判断合并主体。
