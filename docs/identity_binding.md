# 可信身份与绑定现况

当前 Companion Core v0.5.0/schema 5。微信与QQ本人登记、命令和普通聊天已获用户手机确认；M07指定属性共享/解绑已实现并通过本地自动检查，真实双端绑定尚未执行。线上有效绑定和待确认码均为0，默认保持独立记忆。

可信身份来自平台实例、受控真实机器人账号、SDK事件sender、角色和私群范围；昵称或正文自称本人不改变权限。微信self_id为适配器ID、QQ C2C为unknown_selfid，不能当真实账号，使用已核实的bot_account_ids。QQ本人登记另需一次性短期码和实际SDK AppID核对；该登记本身不共享记忆。只接受当前实例唯一白名单本人，不处理好友或群。

M07不合并person、不复制事实。源本人私聊发送 `/绑定发起 QQ 音乐,称呼`（或目标微信），明确1至10个普通事实属性；程序生成96位随机码，仅在独立权威账本存哈希，10分钟单次有效。目标必须是另一个已核实的唯一机器人本人私聊、同一角色；先 `/绑定查看 码` 核对双向范围，再 `/绑定接受 码`。预览不启用共享，模型不能生成或认可绑定。新申请作废旧待确认码，重新绑定替换范围，不隐式扩大。

共享只在读取时查询两端原始user_explicit事实，标明来源渠道和绑定编号；同名本地事实优先，不覆盖或转抄另一端，不转发第三端共享。事件、情绪、历史、互动边界和主动发送权限不共享。注入仍受总1200 UTF-8字节预算限制。两端保存不同值时各自保留，不把绑定当成自动更正。

`/绑定状态` 显示编号和范围；任一端 `/解绑 完整编号` 撤销。解绑在同一主库/账本事务中清理两端插件活跃上下文、候选、模拟语气和待执行提醒，原始事实各自保留。更正也会使另一端旧上下文/在途写入票据失效。任一端 `/忘记 属性` 同时撤回该属性的共享，避免从另一端重新注入；不删除另一端原始事实。`/忘记 全部` 或 `/停止记忆` 撤销关联共享和待确认码，恢复记忆不会自动恢复共享。删除、解绑不声称清除其他界面显示、第三方服务或旧备份正文。

当前白名单、账号或范围元数据失效时，读取前核对并永久撤销原授权，不向新账号转移。绑定、用码、撤回范围和解绑保留无事实值审计。共享权限、码消费和撤销位于最新独立deletions.sqlite；旧主库恢复先重放最新修订，不能复活已撤回共享或旧上下文，不能回滚账本。schema 5是防止旧代码误读共享上下文的兼容性界线；v0.4.x不可直接打开在线库。

18项绑定专项与38项真实框架类/假模型集成检查通过，整体202项本地检查通过。覆盖伪造/相似身份、错误机器人或角色、群隔离、过期/重复码、未预览拒绝、事务失败回滚、共享范围、更正/删除/停用、解绑后上下文与队列清理、旧快照及4→5加法迁移。真实旧库隔离升级确认身份/事实/范围逐行不变，未用测试绑定修改本人数据。手机双端绑定、真实模型跨端问答仍待本人回来后测试，不以本地检查替代。
