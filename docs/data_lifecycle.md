# 当前数据生命周期

本版接收显式 `/记住 属性=值` 或“记住，我喜欢听爵士”，冲突必须 `/更正` 或明确“更正……”请求。支持“忘记我的音乐偏好”等中文管理意图。普通聊天、模型推测、疑问、角色扮演和外部资料不自动写事实；含糊的“忘掉刚才的资料”明确提示尚未执行。敏感凭据关键词阻断不是完整敏感信息分类器。

- 事实存储在插件 data 目录 memory.sqlite，附来源哈希、范围、时间、版本和 supersedes。更正物理移除旧值，不保留旧正文。
- 独立 deletions.sqlite 保存被删事实 ID、来源哈希、范围、时间、删除代次、停用策略；不存被删值。两库采用 SQLite ATTACH + rollback journal + FULL 同步，在同一事务内处理更正和删除。
- 删除会清掉匹配活跃事实及同一范围全部 turns，阻断旧来源，使开始于旧代次的任务票据失效。用户用新消息明确重新提供可保存；旧来源不能回写。无摘要、向量索引或后台抽取队列，故不伪造这些模块的重建验证。
- 短期 turns 按用户范围及会话隔离，最多 3 轮，读取时淘汰 24 小时以前内容。保存删除代次，旧备份恢复时清掉代次落后的轮次；删除后的新问题及“不知道”答复可成为新的轮次。更正和停用也清空旧轮次。不把这些轮次自动抽取为事实。
- `/停止记忆` 停止保存及注入；保留管理查看/导出/删除。停用状态写独立账本，旧快照恢复不能绕过停用。
- `/忘记 属性` 或 `/忘记 全部` 同时清理当前 AstrBot LLM 会话及当前 WebChat 显示历史。其他显示会话、已导出文件、旧备份不会被宣称已删，但不进入当前模型上下文。没有自动重抽取历史。
- event receipts 只保存哈希和占位时间，当前无自动淘汰；防止旧消息重放。身份映射、有效事实保留到用户删除；整个身份删除及保留期限自动清理尚未实现。
- 备份建议本地保留最多 7 天，手动淘汰；自动清理尚未设置。删除账本必须保持最新且独立可靠，不能随旧快照一起回滚。相关日志及导出文件也需用户在本机管理。
- 本地逻辑删除不能保证磁盘取证不可恢复，也不能删除第三方模型服务数据。本轮有真实模型请求，合成测试事实及对话已发送给 DeepSeek；不能声称本地删除也清除了提供商数据。

P3 限制：中文显式意图为受控规则，尚无广泛自然语言自动抽取、事件/关系数据、摘要和语义向量索引；召回采用结构化属性/主题优先、少量同义词与二字片段，短词有兜底。真实 20 题首轮 19/20，修正后仅复测过失败题；不能推断任意中文语义质量。模型不知道某事实不等于本机完全没有聊天记录。
