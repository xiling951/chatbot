# 当前数据生命周期

本版接收显式 `/记住 属性=值` 或“记住，我喜欢听爵士”。自动记忆默认关闭，用 `/自动记忆 开` 单独启用当前可信主体/角色/范围，`/自动记忆 关` 停止抽取并作废候选。开启后只从当前本人消息中提取受控明确陈述，覆盖 20 类测试事实及称呼/边界；不重抽历史、不读取模型输出。疑问、引用、假设、角色扮演和外部资料不抽取。敏感凭据、长数字与邮箱阻断不是完整敏感分类器；不自动保存详细住址。

新事实直接保存；没有时间变化标记的冲突保留 candidates，当前事实不变。`/待确认记忆` 查看，`/确认记忆 编号` 按当前主体、原事实 ID 和删除代次验证。明确“现在……”变化或 `/更正` 可更正旧值。冲突消息不进入短期 turns，避免未确认值从历史绕入后续回答。每次确认、删除、更正、停止或自动记忆开关变化均使旧候选/任务票据失效。

schema 3 为加法迁移：scope_metadata 明确 persona/person/visibility；relationships 视图引用同一份称呼/边界事实，不复制正文。`/记录事件` 保存 user_reported，`/记录计划` 保存 shared_plan；时间表示记录时间，不冒充事件实际发生或外部核实。无 AI 真实活动证据时不接受 verified_ai_activity。记录计划不会安排提醒。`/共同事件` 查看，`/忘记 共同事件` 删除，全部删除覆盖事实、候选和事件。导出包含事实、候选、关系、事件和自动开关。

- 事实存储在插件 data 目录 memory.sqlite，附来源哈希、范围、时间、版本和 supersedes。更正物理移除旧值，不保留旧正文。
- 独立 deletions.sqlite 保存被删事实/事件/候选 ID、来源哈希、范围、时间、删除代次、停用和自动抽取策略；不存被删值。两库采用 SQLite ATTACH + rollback journal + FULL 同步，在同一事务内处理更正和删除；恢复时失效旧候选及旧短期历史，重放最新开关，不能从旧快照重新开启自动记忆。
- 删除会清掉匹配活跃事实及同一范围全部 turns，阻断旧来源，使开始于旧代次的任务票据失效。用户用新消息明确重新提供可保存；旧来源不能回写。无摘要、向量索引或后台抽取队列，故不伪造这些模块的重建验证。
- 短期 turns 按用户范围及会话隔离，最多 3 轮，读取时淘汰 24 小时以前内容。保存删除代次，旧备份恢复时清掉代次落后的轮次；删除后的新问题及“不知道”答复可成为新的轮次。更正和停用也清空旧轮次。不把这些轮次自动抽取为事实。
- `/停止记忆` 停止保存及注入；保留管理查看/导出/删除。停用状态写独立账本，旧快照恢复不能绕过停用。
- `/忘记 属性` 或 `/忘记 全部` 同时清理当前 AstrBot LLM 会话及当前 WebChat 显示历史。其他显示会话、已导出文件、旧备份不会被宣称已删，但不进入当前模型上下文。没有自动重抽取历史。
- event receipts 只保存哈希和占位时间，当前无自动淘汰；防止旧消息重放。身份映射、有效事实保留到用户删除；整个身份删除及保留期限自动清理尚未实现。
- 本机加密运行快照保留 7 天，在线每 24 小时到期检查，只自动淘汰本项目命名的加密包；历史手动快照不擅自删除。当前删除账本永不轮转或随旧快照回滚。观察/启动日志限定本项目命名保留 8 天；其他导出及历史文件仍由用户在本机管理。见 backup_restore.md。
- 本地逻辑删除不能保证磁盘取证不可恢复，也不能删除第三方模型服务数据。本轮有真实模型请求，合成测试事实及对话已发送给 DeepSeek；不能声称本地删除也清除了提供商数据。

P3 限制：自动抽取是受控规则，不代表任意中文语义抽取；尚无摘要和向量索引，也没有后台抽取队列。称呼/边界按范围优先注入，相关事件与事实共用 1200 UTF-8 字节上限。真实自动记忆跨会话问答 20/20 及关联 7/7，含隔离、确认、时间更正与删除，不能替代真实跨天或手机验收。模型不知道某事实不等于本机完全没有聊天记录。

已部署 schema 4：tasks/executions/outbox 保存有来源的本人提醒；ledger.proactive 和 ledger.submissions 独立保留授权代次、投递状态和额度日期，不随旧主库回滚。删除/更正/停用会取消同范围待执行任务、清空候选正文并阻断任务旧来源；确认已有平台提交时仍保留其真实接受/unknown 状态，不伪称撤回。用户会收到已取消提醒的提示。取消单个提醒也写入独立最小账本，防止旧快照重新安排。

模拟互动风格在 emotions/emotion_events，数值、规则理由、来源哈希及删除代次，不保存原消息正文。范围按同一可信 scope 隔离，6 小时半衰期回到中性基线；普通聊天次数和缺席不增加或惩罚关系值。仅影响受控语气提示，不是用户事实或真实感受，不能改变权限。导出包含模拟状态及来源事件，记忆删除/停用和旧快照恢复会失效其旧内容。已部署并通过真实 Web 隔离/删除回归，不等于自然度或真实情感评分通过。
